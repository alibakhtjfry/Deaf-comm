# Reproducibility Guide

This project is based on an external research system.
To ensure experiments can be reproduced:

- Original dataset: PHOENIX-2014T
- Pose extracted using OpenPose-based skeletonization
- Model trained with progressive transformers

To reproduce:
1. Install dependencies from requirements.txt
2. Download dataset (not included due to license)
3. Place dataset in Data/
4. Run training or inference scripts

This ensures the work is verifiable and scientifically valid.
